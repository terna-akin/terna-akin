# Terna Akin-Akinbisola — Portfolio

A responsive static portfolio for GitHub Pages. No installation or build step is required. Open `index.html` to preview.

## Publish on GitHub Pages

1. Create a repository named `YOUR-USERNAME.github.io` for your main portfolio, or use a repository named `terna-portfolio` for a project site.
2. Upload the contents of this folder directly to the repository root. Ensure `index.html` is at the root, rather than inside an extra folder.
3. In Settings → Pages, choose **Deploy from a branch**, select **main** and **/ (root)**, and save.
4. Use the website address displayed by GitHub once deployment finishes.

All asset links are relative, so the site works at either a root domain or repository subpath.
